# Plan: Implement HurriCacheGrpcService in Python

## Background

The project contains a protobuf definition (`proto/cache.proto`) with the `HurriCacheGrpcService` service definition. The project currently has no Python files. We need to generate gRPC stubs and implement a Python client.

## Requirements

- Generate Python gRPC stubs from `proto/cache.proto`
- Create a standard Python package structure
- Implement `HurriCacheGrpcService` client with all RPC methods
- Use `grpcio` and `grpcio-tools` for gRPC generation
- Support both sync and async clients

## Implementation Steps

### 1. Project Structure

```
/ext/hurricache-python-client/
├── pyproject.toml              # Project metadata, dependencies
├── proto/
│   └── cache.proto             # Existing
├── hurricache/
│   ├── __init__.py
│   ├── grpc/
│   │   ├── __init__.py
│   │   ├── cache_pb2.py        # Generated from proto
│   │   ├── cache_pb2_grpc.py   # Generated from proto
│   │   └── client.py           # HurriCacheGrpcService client implementation
│   └── replication/
│       ├── __init__.py
│       └── client.py           # DataReplicationService client
└── tests/
    └── test_client.py          # Basic tests
```

### 2. Generate gRPC Stubs

Run `grpc_tools.protoc` to generate Python stubs from `proto/cache.proto`:

```bash
python -m grpc_tools.protoc \
  -I proto/ \
  --python_out=hurricache/grpc/ \
  --grpc_python_out=hurricache/grpc/ \
  proto/cache.proto
```

### 3. Create `pyproject.toml`

Dependencies:
- `grpcio>=1.60.0`
- `grpcio-tools>=1.60.0`

Include a build script or Makefile target to regenerate stubs.

### 4. Implement `hurricache/grpc/client.py`

Create a `HurriCacheClient` class that wraps the generated stub:

- Constructor accepts `host`, `port`, and optional `credentials`
- Provides a `channel` property that creates/returns a gRPC channel
- Exposes all RPC methods from `HurriCacheGrpcService`:
  - `lock_object`, `unlock_object`
  - `set_ttl`, `get_ttl`
  - `create_key_value`, `get_value`, `get_and_delete_value`, `exist_key`, `update_value`, `remove`
  - `create_container`, `get_container` (streaming), `get_size`
  - `get_tail`, `get_head`, `get_value_in_container`, `exist_key_in_container`
  - `get_and_remove_front`, `get_and_remove_tail`, `get_and_remove_element_at_position`
  - `get_and_delete_value_in_container`, `update_value_in_container`
  - `get_element_at_position`, `get_element_in_range` (streaming)
  - `remove_head`, `remove_tail`, `remove_element_at_position`
  - `remove_from_container_by_key_value`, `remove_in_container`
  - `add_element_to_tail`, `add_element_to_head`, `add_element`, `add_element_to_position_by_value`
  - `atomic_load`, `atomic_load_and_delete`, `atomic_create`, `atomic_store`
  - `atomic_exchange`, `atomic_add`, `atomic_sub`, `atomic_or`, `atomic_and`, `atomic_xor`
  - `atomic_compare_and_set`
- Each method validates inputs and returns the response directly from the stub
- Support for async via `aiogrpc` or `grpc.aio`

### 5. Create `hurricache/grpc/__init__.py`

Export the main client class:

```python
from hurricache.grpc.client import HurriCacheClient
```

### 6. Create `hurricache/__init__.py`

Package init with version and exports.

### 7. Add Tests

Basic unit tests for the client using mock channel/stubs.
